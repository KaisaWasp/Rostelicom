# Технический фундамент фронтенда

## Статус

Технический фундамент принят. Базовая дизайн-система, Storybook и визуальные прототипы трёх страниц реализованы; предметная бизнес-логика и подключение API остаются следующими этапами.

## Реализованный стек

- React 19 и Vite 6.
- TypeScript в strict mode.
- Ant Design с русской локализацией.
- Feature-Sliced Design.
- Redux Toolkit и React Redux.
- React Router.
- CSS Modules как соглашение для будущих компонентов.
- ESLint, Prettier и Stylelint.

## Структура

```text
src/
  app/
    providers/
    router/
    store/
    styles/
  pages/
    market-radar/
    investment-navigator/
    deal-calculator/
  shared/
    config/
    lib/
    styles/
    ui/
```

Слой `pages` реализован. Слои `widgets`, `features` и `entities` будут добавляться вместе с утверждёнными сценариями и API-контрактами. Каждый срез обязан предоставлять минимальный публичный API через `index.ts`.

## Управление состоянием

- Состояние компонента остаётся локальным.
- Воспроизводимые фильтры хранятся в URL search params.
- Redux Toolkit используется для общего клиентского состояния.
- Серверное состояние подключается через RTK Query после утверждения API-контрактов.

## Отложенные решения

- Реальные API-контракты и RTK Query — после согласования backend API.
- Интерактивная карта и библиотека графиков — после утверждения источника геоданных и требований к визуализациям.
- Реальная расчётная логика, экспорт CSV/CRM и генерация КП — после утверждения бизнес-правил.

## Проверки

Выполнены: `typecheck`, `lint`, `stylelint`, `format:check`.

Команда `build` намеренно не выполнялась по явному ограничению пользователя.
