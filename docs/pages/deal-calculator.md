# Калькулятор сделок

Цель: показать прозрачный предварительный диапазон стоимости по параметрам сделки.

Экран содержит шаги сценария, форму параметров, состав решения, закрепляемую панель результата и таблицу аналогов. Значения прототипа не являются коммерческим предложением. На мобильном устройстве результат размещается после формы.

Используются `PageHeader`, `DataPanel`, Ant Design `Steps`, `Form`, `Table` и `Alert`. В Storybook представлены заполненный и исходный сценарии.
