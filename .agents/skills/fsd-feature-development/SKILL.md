# Разработка функциональности

Прочитай требования, связанные срезы и источник данных. Определи размещение логики в `app`, `pages`, `widgets`, `features`, `entities` или `shared`; соблюдай направленность зависимостей и public API.

Выбирай local state для состояния компонента, URL для воспроизводимых фильтров, Redux Toolkit для общего клиентского состояния и RTK Query для принятого серверного состояния. Создавай типы, модель, UI и API среза без дублирования кэшей. Используй CSS Modules и дизайн-токены. Выполни доступные проверки и сообщи их фактический статус.
