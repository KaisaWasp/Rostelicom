# Дизайн система

Сначала изучи утверждённые материалы `docs/brand/`, существующие токены и `src/shared/ui/`. Используй Ant Design через документированные theme tokens и `ConfigProvider`; не переопределяй внутренние нестабильные селекторы.

Размещай универсальные компоненты в `src/shared/ui/<component-name>/`, применяй CSS Modules и публикуй только необходимый API через `index.ts`. Добавляй Storybook stories для значимых состояний. Не создавай брендовые значения без подтверждённого источника и не переноси бизнес-логику в `shared/ui`.
