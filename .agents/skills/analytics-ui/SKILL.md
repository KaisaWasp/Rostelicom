# Аналитические компоненты

До выбора визуализации определи контракт: типы, единицы, даты, временные зоны, null, агрегации и ограничения объёма. Разделяй преобразование данных и их отображение.

Применяй утверждённые токены и существующий UI. Покрывай loading, error и empty; для больших наборов оцени серверную пагинацию или виртуализацию. Проверяй значения, форматирование, сортировку, фильтры и доступность. Не кодируй смысл только цветом, а mock-данные маркируй.
